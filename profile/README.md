# Russell County Democratic Committee

This GitHub organization is used exclusively for access management and verification purposes for the Russell County Democratic Committee's digital infrastructure.

## Membership

Membership in this organization is restricted to:
- Current committee officers
- Authorized technology volunteers

Membership does not grant access to any public-facing resources and is used solely to verify identity for internal committee tools.

## Not a Public Organization

This organization does not host public projects or accept outside contributions. If you are a Russell County Democrat interested in getting involved, please visit [RussellDems.org](https://russelldems.org) or email us at [info@russelldems.org](mailto:info@russelldems.org).
